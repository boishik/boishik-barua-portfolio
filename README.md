# Boishik Barua — AI / ML Portfolio Website

This is a ready-to-use responsive portfolio built with **HTML, CSS, and vanilla JavaScript**.

## Included
- `index.html` — page structure and content
- `styles.css` — responsive AI-themed visual design
- `script.js` — mobile navigation, scroll reveal animations, typewriter line, and gallery slideshow
- `assets/images/` — placeholder profile and achievement slideshow images
- `assets/docs/Boishik_Barua_CV.pdf` — CV copy for the Download CV button

## How to run
Open `index.html` in any modern browser.

## Recommended personal edits
1. Replace `assets/images/profile-placeholder.svg` with your real professional photo, keeping the same filename or updating the path in `index.html`.
2. Replace:
   - `achievement-1.svg`
   - `achievement-2.svg`
   - `achievement-3.svg`
   with your actual university award photos.
3. In the Contact section of `index.html`, replace the placeholder GitHub and LinkedIn `href="#"` links with your real profile URLs.
4. Update any project descriptions or achievements when your CV changes.
